## What you need

A browser is enough for Chat. Code, Bot, plugins, and Design need a signed-in account. Desktop and CLI are optional until you want This PC, SSH, or Design's working UI.

## 1. Open Chat

1. Go to [cortex.foundation](https://cortex.foundation).
2. Select **Chat** from the product switcher.
3. Type a question and send. Answers stream as they arrive.

Chat works before you sign in. New chat starts a thread — it is an action, not a selected row in the sidebar.

## 2. Sign in when you need more

Sign in when you want projects, plugins, Code, Bot, or Design. See [Accounts](/getting-started/accounts).

Exact `/code` and `/bot` stay public product pages if you are not signed in. The working UI for those products is for members.

## 3. Take a first session on each surface

| Surface | First useful thing | Guide |
| --- | --- | --- |
| **Chat** | Attach a file and keep the thread in a project | [Chat quickstart](/chat/quickstart) |
| **Code** | Connect GitHub and start a Cloud session | [Code](/code) |
| **Bot** | Create a bot and open its computer | [Bot](/bot) |
| **Design** | Host a canvas from Chat or Code, then open the desktop app | [Design](/design) |

## 4. Install desktop or CLI if you need them

This PC and SSH exist on the [desktop app](/getting-started/desktop) and the [CLI](/getting-started/cli), not in the browser. Web Code and web Bot stay Cloud-only. Design's working UI is a separate desktop app.

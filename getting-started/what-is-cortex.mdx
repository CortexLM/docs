Cortex is four products that share an account at `cortex.foundation`. Use Chat for conversation, Code for a repository, Bot for an always-on teammate, and Design for persistable canvases.

## The four products

| Product | What you open | Who it is for |
| --- | --- | --- |
| **Cortex Chat** | `/` | Everyone, including before you sign in |
| **Cortex Code** | `/code` | Signed-in members (others see the public page) |
| **Cortex Bot** | `/bot` | Signed-in members (others see the public page) |
| **Cortex Design** | Desktop app | Signed-in members |

Chat works unsigned. Code, Bot, plugins, and Design need a signed-in account so a grant you could never revoke cannot be created.

## When to use which

| Stay in Chat | Open Code | Open Bot | Open Design |
| --- | --- | --- | --- |
| Questions, writing, research, pictures, origin checks | A repository, a Cloud guest, diffs, a pull request | An always-on teammate with a computer, routines, approvals | Frames, notes, and a Library on a board hosted from Chat or Code |

Chat does not run Code's workspace shell or Bot's computer. Design canvases are not Chat markdown sidecars.

## Language

English is the source of truth for interface copy. The web app localizes it. Product names stay untranslated.

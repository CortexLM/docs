## Guest and member

| | Guest | Member |
| --- | --- | --- |
| Chat | Yes | Yes |
| Projects, Library, memory | No | Yes |
| Plugins and MCP servers | No | Yes |
| Code or Bot working UI | No — public product pages only | Yes |
| Design canvases | No | Yes |

A guest cannot connect a plugin or MCP server, cannot open Code or Bot working UI, and cannot create a grant they could never revoke.

## Same account everywhere

The CLI and desktop app use the same Cortex account as the web app. Sign in from those apps when they ask.

## Your data

Export your data or delete your account from **Settings → Data & privacy**. Signed-in members confirm two-factor first. See [Security](/security/overview).

<Note>
There is no teammate-invite on a Chat thread. Cortex Chat is per account, not a shared workspace. See [Sharing and teams](/chat/sharing).
</Note>

Download the Cortex desktop app from `https://releases.cortex.foundation`.
Sign in from the app when it asks — the same account as the web app.

This PC and SSH for Code and Bot exist on the desktop app (and the CLI),
not in the browser. Cortex Design's working UI is a separate desktop app.

Web Cortex Code and Cortex Bot stay Cloud-only.

## Catalog

| Group | Tools |
| --- | --- |
| Box | `read`, `write`, `edit`, `shell` |
| Computer use | `screenshot`, `grounded_click`, `type`, `hotkey`, `scroll`, `drag`, `wait`, `open_app`, `switch_app`, `save_note`, `code_agent` |
| Browser | `browser` |
| Web | `web_search`, `web_fetch` |
| Memory and skills | `update_memory`, `skill`, `routine` |
| User-visible | `send_to_user`, `ask_user`, `notify`, `secret_request` |
| Nested | `task` |
| Agents | `send_to_agent`, `create_agent`, `create_channel` |
| Artifacts | `read_artifact`, `grep_artifact` |
| Plugins | Plugins enabled for **Bot** |

This is exhaustive against the parent declarations — not a Chat subset.

## Background tasks

Background `task` returns `{ ok, id, status: "queued" }` immediately. Children emit `task_started` / `task_progress` / `task_completed` / `task_failed`.

Dangerous computer steps and connected-app changes park behind [Approvals](/bot/approvals).

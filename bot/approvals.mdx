Confirm widgets are Allow / Deny / Always. Confirming **runs** the parked action — a connected-app change or a dangerous computer step.

<Frame>
  <img src="/images/frames/approvals.svg" alt="Bot confirm sheet with Allow, Deny, and Always" />
</Frame>

## 1. Read the parked step

The widget names the tool and what it will do. Nothing runs until you choose.

## 2. Choose

| Choice | What happens |
| --- | --- |
| **Allow** | Runs the parked action this time |
| **Deny** | Does not run it |
| **Always** | Runs it, and remembers that choice for next time |

Denying does not run it. Always is for the next time that same kind of step appears — not a blanket for every tool.

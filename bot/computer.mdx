| Host | Where | Desktop |
| --- | --- | --- |
| Cloud | Isolated guest | Yes (desktop, browser, shell) |
| This PC | Your machine | Desktop app only |
| SSH | A registered host | Shell only, no desktop |

The browser cannot choose This PC or SSH. Cloud Bot still has a shell and a
live desktop.

Open desktop / Sleep live on the Computer rail. Connecting is only while the
guest is starting. A running guest that is not live is Stream Unavailable —
not stacked under Connecting.

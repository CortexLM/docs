| | |
| --- | --- |
| HTTP | `429` |
| `code` | `quota_exceeded` |
| `type` | `https://docs.cortex.foundation/problems/quota_exceeded` |
| Retryable | no |

A plan quota window is exhausted. Carries `resets_at`, `retry_after_seconds`, `quota_key`, `plan`, and optionally `fallback_model`. Not retryable: wait for the window to reset, or move to a plan with higher ceilings. Note that `images_per_day` is a quota rather than a paywall, because every plan including Guest can generate images, in different daily amounts.

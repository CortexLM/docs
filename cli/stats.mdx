# cortex stats

Display token usage and cost statistics for your Cortex sessions.

## Usage

```bash
cortex stats [OPTIONS]
```

## Examples

```bash
# Show stats for last 30 days (default)
cortex stats

# Last 7 days
cortex stats --days 7

# Filter by provider
cortex stats --provider anthropic

# Filter by model
cortex stats --model claude-sonnet-4

# Detailed breakdown
cortex stats --verbose

# JSON output
cortex stats --json
```

## Options

| Flag | Short | Description | Default |
|------|-------|-------------|---------|
| `--days` | `-d` | Number of days to include | 30 |
| `--provider` | `-p` | Filter by provider name | All |
| `--model` | `-m` | Filter by model name | All |
| `--verbose` | `-v` | Show detailed breakdown | `false` |
| `--json` | | Output as JSON | `false` |

## Statistics Breakdown

### Summary

| Metric | Description |
|--------|-------------|
| Sessions | Total conversation sessions |
| Messages | Total messages exchanged |
| Input Tokens | Tokens sent to the model |
| Output Tokens | Tokens generated by the model |
| Total Tokens | Combined token count |
| Est. Cost | Estimated cost in USD |

### By Provider

Breakdown of usage per AI provider:
- Anthropic (Claude models)
- OpenAI (GPT models)
- Google (Gemini models)
- Groq, Mistral, DeepSeek, etc.

### By Model (Verbose)

When using `--verbose`, shows per-model breakdown:

```
By Model
------------------------------------------------------------
  Model                               Sessions       Cost
  claude-sonnet-4-20250514                  25      $8.50
  claude-3-5-haiku-20241022                 10      $2.00
  gpt-4o                                     5      $1.50
  ... and 2 more models
```

### Tool Usage

Shows how often each tool was called:
- `Read` - File reading
- `Edit` - File editing
- `Execute` - Command execution
- `Grep` - Pattern searching
- `Glob` - File finding
- And more...

## Filtering

### By Date Range

```bash
# Last week
cortex stats --days 7

# Last year
cortex stats --days 365
```

### By Provider

```bash
# Anthropic only
cortex stats --provider anthropic

# OpenAI only
cortex stats --provider openai
```

### By Model

```bash
# Specific model
cortex stats --model claude-sonnet-4

# Partial match
cortex stats --model haiku
```

## Use Cases

<AccordionGroup>
  <Accordion title="Cost Monitoring">
    Track spending across providers:
    ```bash
    # Weekly cost check
    cortex stats --days 7
    
    # Monthly report
    cortex stats --days 30 --json > monthly-report.json
    ```
  </Accordion>
  
  <Accordion title="Usage Optimization">
    Identify expensive operations:
    ```bash
    # Check which models are used most
    cortex stats --verbose
    
    # Compare provider costs
    cortex stats --provider anthropic
    cortex stats --provider openai
    ```
  </Accordion>
  
  <Accordion title="Team Reporting">
    Generate reports for team:
    ```bash
    # Export detailed stats
    cortex stats --days 30 --verbose --json > team-stats.json
    ```
  </Accordion>
</AccordionGroup>

```

```

# CLI Overview

Cortex CLI provides both interactive and non-interactive modes for AI-assisted coding.

## Basic Usage

```bash
# Start interactive TUI (default)
cortex [OPTIONS] [PROMPT]

# Use a subcommand
cortex [OPTIONS] <COMMAND> [ARGS]
```

When no subcommand is specified, Cortex starts the interactive Terminal User Interface (TUI).

## Global Options

### Model Configuration

| Flag | Short | Description | Example |
|------|-------|-------------|---------|
| `--model` | `-m` | Model to use | `--model claude-sonnet-4` |
| `--oss` | | Use open-source/local providers | `--oss` |
| `--profile` | `-p` | Configuration profile from config.toml | `--profile work` |

### Security & Sandbox

| Flag | Short | Description | Example |
|------|-------|-------------|---------|
| `--sandbox` | `-s` | Sandbox policy for shell commands | `--sandbox workspace-write` |
| `--ask-for-approval` | `-a` | Approval policy (ask, medium, low, yolo) | `--ask-for-approval medium` |
| `--full-auto` | | Enable automatic mode with sandboxing | `--full-auto` |
| `--dangerously-bypass-approvals-and-sandbox` | | Skip all safety checks (DANGEROUS) | |

### Workspace & Files

| Flag | Short | Description | Example |
|------|-------|-------------|---------|
| `--cd` | `-C` | Working directory | `--cd /path/to/project` |
| `--add-dir` | | Additional writable directories | `--add-dir ../shared` |
| `--image` | `-i` | Attach image files to prompt | `--image screenshot.png` |

### Features

| Flag | Description |
|------|-------------|
| `--search` | Enable web search capability |

### Debugging & Output

| Flag | Short | Description |
|------|-------|-------------|
| `--log-level` | `-L` | Set verbosity (error, warn, info, debug, trace) |
| `--debug` | | Write all logs to ./debug.txt |

## Quick Examples

```bash
# Start with a prompt
cortex "explain this project"

# Use a specific model
cortex --model gpt-4o "review this code"

# Non-interactive execution
cortex run "fix the bug in main.rs"

# Headless CI/CD mode
cortex exec --auto medium "run tests and fix failures"

# Resume last session
cortex resume --last

# List available models
cortex models

# Check usage statistics
cortex stats --days 30
```

## File Paths

| Path | Description |
|------|-------------|
| `~/.config/cortex/config.toml` | Main configuration file |
| `~/.local/share/cortex/sessions/` | Session storage |
| `~/.cache/cortex/logs/` | Log files |
| `~/.cortex/agents/` | Personal agents |
| `.cortex/agents/` | Project-specific agents |

## Environment Variables

| Variable | Description |
|----------|-------------|
| `CORTEX_HOME` | Override config directory |
| `CORTEX_API_KEY` | API key |
| `CORTEX_MODEL` | Default model |
| `CORTEX_LOG_LEVEL` | Log verbosity |
| `NO_COLOR` | Disable colored output |
| `VISUAL` / `EDITOR` | Editor for /edit command |

# cortex models

List all available AI models from configured providers.

## Usage

```bash
cortex models [OPTIONS] [PROVIDER]
```

## Examples

```bash
# List all models
cortex models

# Filter by provider
cortex models anthropic
cortex models openai
cortex models google

# JSON output
cortex models --json
```

## Options

| Flag | Description |
|------|-------------|
| `PROVIDER` | Filter by provider name |
| `--json` | Output in JSON format |

## Using Models

### Command Line

```bash
# Use specific model
cortex --model gpt-4o "explain this code"

# With run command
cortex run --model claude-sonnet-4 "review for bugs"

# With exec command
cortex exec --model gemini-2.0-flash "analyze codebase"
```

### Model Aliases

For convenience, Cortex supports short aliases:

| Alias | Full Model ID |
|-------|---------------|
| `sonnet` | `claude-sonnet-4-20250514` |
| `opus` | `claude-opus-4-20250514` |
| `haiku` | `claude-3-5-haiku-20241022` |

```bash
cortex --model sonnet "quick task"
```

### In Configuration

Set default model in `~/.config/cortex/config.toml`:

```toml
[model]
default = "claude-sonnet-4-20250514"
provider = "anthropic"
```

### In Agents

Override model per agent:

```yaml
---
name: my-agent
model: gpt-4o
---
```

## Local Models

### Ollama

Run models locally with Ollama:

```bash
# Install Ollama (https://ollama.ai)
# Then pull a model
ollama pull qwen2.5-coder:32b

# Use with Cortex
cortex --oss --model qwen2.5-coder:32b "task"
```

### LM Studio

Connect to LM Studio:

```bash
# Start LM Studio and load a model
# Then use with Cortex
cortex --oss --model lmstudio/my-model "task"
```

## Cost Tracking

Track model usage and costs:

```bash
# View usage statistics
cortex stats --days 30

# By model
cortex stats --verbose
```

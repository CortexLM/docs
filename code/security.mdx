## Install and review

1. Sign in and open `/code/security` in the app.
2. Install the **Cortex Security** GitHub App from the product.
3. It reviews pull requests and posts a check run named Cortex Security.

A review that could not run is failed, never an approval.

## What it is not

This is not the [Connect GitHub](/code/github) control used to clone repositories for Code. Policy lives at `/code/security/policy` in the app. A pull request cannot reduce the scrutiny it receives.

The docs article [Security](/security/overview) is how Cortex handles data and sandboxes — not this inbox.

title: "Cortex Security"
description: "GitHub App pull-request review. /security is the sitelink; /code/security is the inbox."
---

`/code/security` is the signed-in inbox. `/security` on cortex.foundation is
the public product page. They are different routes.

Install the **Cortex Security** GitHub App from the product. It reviews pull
requests and posts a check run named Cortex Security. A review that could not
run is failed, never an approval.

This is not the Connect GitHub control used to clone repositories for Code.
Policy lives at `/code/security/policy` in the app. A pull request cannot
reduce the scrutiny it receives.

A Code session is a timeline of the task you asked and the work that followed — files read, edits, commands, a plan. It is not a Chat transcript.

## What the header shows

The header shows run state. **Stop** cancels the live turn.

## Ask, Plan, Agent

Ask / Plan / Agent choose how much the agent may change. A later follow-up can pick a different mode. Details: [Ask, Plan, Agent](/code/interactions).

## Start a session

1. Sign in and open Code. Exact `/code` is the public page if you are not signed in.
2. [Connect GitHub](/code/github) if the work needs a repository.
3. Describe the change. Watch the timeline — not a Chat bubble dump.
4. Stop if the turn is going the wrong way.

Web Code is Cloud only. This PC and SSH are [desktop](/code/desktop) and [CLI](/code/cli) surfaces.

---
title: "Sessions"
description: "A session is a turn timeline, not a chat transcript."
---

A Code session is a timeline of the task you asked and the work that followed —
files read, edits, commands, a plan. It is not a Chat transcript.

The header shows run state. Stop cancels the live turn. Ask / Plan / Agent
choose how much the agent may change; a later follow-up can pick a different
mode.

---
title: "Connect GitHub"
description: "Connect GitHub in Cortex Code. No personal-access-token field."
---

Cortex Code reaches repositories through **Connect GitHub** — on Code Home,
the repository picker, and Settings → Integrations.

There is no personal-access-token field. If GitHub is not available on this
deployment, the product draws no Connect control. If the connection lapsed,
the product says Reconnect.

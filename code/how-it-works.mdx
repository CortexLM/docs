---
title: "How Code works"
description: "Workspace tools execute inside the attached guest."
---

A Code Cloud session turn executes `read_file`, `write_file`, `edit_file`,
`glob`, `grep`, `bash`, `todo_read`, `todo_write` **inside the attached
Firecracker guest**. Not in the API process. Not in the 256 MiB Chat Python
sandbox. `python` is Chat-only; a Code turn runs the guest's own Python
through `bash`.

If the session names a repository and no runtime is attached, the harness
auto-starts, attaches, and prepares that guest. Leaving
`code_runtime_not_attached` as the first command is a bug.

Ask and Plan withhold mutate tools. Plan writes mermaid via `write_plan`.
Compaction is Code's own keep-set and fails closed.

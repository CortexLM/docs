---
title: "Code Cloud runtimes"
description: "Isolated Cloud guest. Not the Chat Python sandbox."
---

Web Code runs in an isolated Cloud guest on the same farm as Bot computers,
without a desktop. Chat's small Python sandbox is a different machine and
cannot see your repository.

If the session names a repository, Cortex starts and prepares that guest.
Without Cloud compute on this deployment, Code says so rather than running
on the API.

title: "CLI"
description: "Same account as the web app. Sign in from the CLI when it asks."
---

The Cortex CLI uses the same account as the web app. It drives Code sessions;
it does not run the model on your laptop.

Install from [software.cortex.foundation](https://software.cortex.foundation).
Sign in from the CLI when it asks — this site does not document the sign-in
protocol.

Deep Research stays in Chat. You plan questions, then run them. Code refuses that field. It is not a Bot skill.

## 1. Plan

1. Stay in **Chat** — not Code, not Bot.
2. Ask for a research plan. The conversation stays in chat mode.
3. Review the plan block. A plan that has not been run still offers **Start** after you come back.

## 2. Run

Start the plan. The harness orchestrates Chat tools plus parallel per-question background children.

| Cap | Limit |
| --- | --- |
| Questions | 32 |
| Sources | 80 |
| In parallel | 8 |
| Fetches per question | 4 |
| Child timeout | 180 seconds |

It does **not** copy Chat's eight-round abort onto that loop, and it does **not** emit tool-start / tool-end chrome.

## 3. Read the report

Plan and report persist as research blocks on the thread. **Start** hides once the run has begun.

<Note>
Deep Research is a Chat turn. Do not look for it in Code's workspace tools or Bot's skill list.
</Note>

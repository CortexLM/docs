The mic in the composer and Listen under an answer appear only when this deployment can transcribe or speak.

## What you will see

| Control | Where | When it appears |
| --- | --- | --- |
| Mic | Composer | This deployment can transcribe |
| Listen | Under an answer | This deployment can speak |

If either control is missing, that capability is off — not a broken button, and not a configuration hint for you to chase.

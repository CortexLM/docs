## 1. Ask for a picture

Describe a complete English scene. You can set a size and, optionally, a seed, a negative prompt, steps (1–50), and guidance (0–20).

## 2. Watch the card

| State | What you see |
| --- | --- |
| `queued` | Improving prompt… |
| `generating` | Skeleton |
| `done` | Library file |
| `error` | Error square — never a spinner |

A Library fetch that fails is the error square. Empty image-cluster URL fails closed before any quota is spent.

## 3. Quota, not a paywall

Free and Guest use `images_per_day`. Exhausting the window is `quota_exceeded`. A plan that does not include image generation at all is `entitlement_required`. See [Plans](/getting-started/plans).

Product name **Cortex-Image-1**; attribution "Built on NVIDIA Cosmos".

Origin check does not run on every Cortex-Image-1 picture. See [Origin check](/chat/origin-check).

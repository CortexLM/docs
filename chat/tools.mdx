---
title: "Tools and connectors"
description: "Chat tools, plugins, and MCP. Code Cloud is not a plugin surface."
---

Chat can search the web, run Python snippets, generate images, check origin, keep memory, and draft canvases. Plugins you enable for **Chat**, plus MCP servers, are available in that conversation.

A connected app is available to Cortex Chat, Cortex Bot, or both. You choose in **Customize**. You must be signed in to connect anything.

Connect GitHub for **Code repositories** with the **Connect GitHub** control in Code — that is not the plugin catalogue. See [Connect GitHub](/code/github).

Library is the files on your account. Attach them from the composer. Chat turns take those files from Library — never a URL you paste.

<Frame>
  <img src="/images/frames/chat-projects.svg" alt="A Library file pinned next to a Chat thread in a project" />
</Frame>

## Add a file

1. Sign in. Library belongs to a member account.
2. Drop a file on the composer, or upload from Library.
3. Type and size checks run at upload. A rejected file is not attached.

## Use a file in Chat

Pick from Library when you start a turn. The conversation receives the file as an attachment, not as a path you typed.

Generated pictures land in Library when [image generation](/chat/images) finishes. A Library fetch that fails shows the error square — never a spinner.

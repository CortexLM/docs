**Check origin** is for authenticity asks with attached media. It does not
run on every Cortex-Image-1 picture.

If origin check is unavailable on this deployment, the product says so rather
than guessing. Assistant copy waits until a verdict paints. iPhone HEIC/HEIF
is accepted on Check origin.

**Check origin** is for authenticity asks with attached media. It does not run on every Cortex-Image-1 picture.

<Frame>
  <img src="/images/product/chat-session.png" alt="A Cortex Chat thread with a reply in the conversation pane" />
</Frame>

## When to use it

1. Attach the media to the turn. iPhone HEIC/HEIF is accepted on Check origin.
2. Ask whether the media is authentic.
3. Wait. Assistant copy waits until a verdict paints.

## If the check cannot run

If origin check is unavailable on this deployment, the product says so rather than guessing. That is fail-closed, not a broken button.

<Note>
Generated Cortex-Image-1 pictures are Library files. Check origin is a separate ask with attached media — not an automatic step after every generation.
</Note>

A **project** groups conversations. An open project in the Chat sidebar is a folder plus that project's chats — not a second selected pill.

Library files are the documents you attach. Chat canvases are markdown sidecars on a conversation; Cortex Design canvases are a different object.

Memory is user-scoped, not a project: [Memory](/chat/memory). Canvases: [Chat canvases](/chat/canvases).

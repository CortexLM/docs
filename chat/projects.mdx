A **project** groups conversations. An open project in the Chat sidebar is a folder plus that project's chats — not a second selected pill.

## What a project holds

| In the project | Not a project |
| --- | --- |
| Threads you start inside it | [Memory](/chat/memory) — account-scoped |
| [Library](/chat/library) files you pin | [Chat canvases](/chat/canvases) — markdown sidecars on a conversation |
| The grouping on later turns | [Design canvases](/design/canvases) — a different object |

## Create and open a project

1. Sign in. Guests cannot create a project.
2. Open **Projects** in the Chat nav.
3. Create a project and start the conversation inside it.
4. Attach or pin Library files from the composer.

A later chat in the same project still sees that grouping.

## Docs in a project

Library files are the documents you attach. Chat turns take those files from Library — never a URL you paste. See [Library](/chat/library).

<Note>
Cortex Chat is per account. Another account cannot see your projects. There is no teammate-invite on a thread. See [Sharing](/chat/sharing).
</Note>

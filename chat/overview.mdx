Cortex Chat is the conversation product at `cortex.foundation`. You can use it before you sign in. Answers stream as they arrive.

## What it is for

Long-running threads, projects, attached documents, Deep Research, images, origin checks, memory, and markdown canvases. Plugins you enabled for **Chat**, plus MCP servers, show up in that conversation.

## When to switch

| Stay in Chat | Open Code | Open Bot |
| --- | --- | --- |
| Questions, writing, research, pictures, origin checks | A repository, a Cloud guest, diffs, a pull request | An always-on teammate with a computer, routines, approvals |

Chat does not run Code's workspace shell or Bot's computer. How the loop runs: [How Chat works](/chat/how-it-works).

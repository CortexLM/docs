## What it is for

Use a thread for questions, writing, and ongoing work. Add documents as context, then keep related threads and Library files together in a project.

- [Projects and docs](/chat/projects) organize your work; [Library](/chat/library) holds files.
- [Deep Research](/chat/deep-research), [image generation](/chat/images), and [origin checks](/chat/origin-check) cover research and media tasks.
- [Memory](/chat/memory) and [markdown canvases](/chat/canvases) help carry context and written work forward.
- [Tools and connectors](/chat/tools) explains built-in tools, Chat-enabled plugins, and MCP servers.

## Start a conversation

Follow the [Chat quickstart](/chat/quickstart) to send a message and attach context. You can chat as a guest, but projects and connections require [sign-in](/getting-started/accounts). Chat is per account, not a shared workspace; see [Sharing and teams](/chat/sharing).

## When to switch

| Stay in Chat | Open Code | Open Bot |
| --- | --- | --- |
| Questions, writing, research, pictures, origin checks | A repository, a Cloud guest, diffs, a pull request | An always-on teammate with a computer, routines, approvals |

Chat does not run Code's workspace shell or Bot's computer. How the loop runs: [How Chat works](/chat/how-it-works).

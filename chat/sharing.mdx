Cortex Chat is **per account**, not a shared workspace product.

  <img src="/images/product/chat-home.png" alt="Placeholder — staging screenshot pending: Cortex Chat home (chat-home.png)" />

## What each kind of user can do

- Chat works before you sign in. A guest cannot connect a plugin or MCP server, cannot open Code or Bot working UI, and cannot create a grant they could never revoke.
- A **member** is a signed-in account. Projects, Library, memory, bots, and Code sessions belong to that account. Another account's threads are not visible.
- There is **no** “invite a teammate to this thread” control. Do not expect a sharing feature — there isn't one.

## Export and deletion

Export and deletion are under **Settings → Data & privacy**. See [Security](/security/overview) and [Accounts](/getting-started/accounts).

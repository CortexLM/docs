A Chat canvas is a markdown sidecar on a conversation. The model can draft one; you can edit it. Closing the canvas keeps your edits.

<Frame>
  <img src="/images/frames/chat-composer.svg" alt="A Chat thread that can open a markdown canvas beside the conversation" />
</Frame>

## What it is not

| Object | What it is |
| --- | --- |
| Chat canvas | Markdown sidecar on a conversation |
| Code file | A file in a Cloud guest |
| [Design canvas](/design/canvases) | A persistable board hosted from Chat or Code |

## Use a canvas

1. Ask Chat to draft a document, or open the canvas on the thread.
2. Edit the markdown. Closing it keeps your edits.
3. Keep Design work on a Design canvas in the desktop app.

<Note>
There is no `/design` mode in the web shell. Chat can still host a Design canvas; the working UI is desktop. See [Design](/design).
</Note>

## 1. Open Chat

1. Launch [cortex.foundation](https://cortex.foundation).
2. Select **Chat** from the product switcher.
3. Start a new chat. It is an action, not a selected row in the sidebar.

## 2. Send a message

Type in the composer and send. Tokens appear as they arrive, then tools, then the finished reply. If the connection drops, the product reconnects. See [Streaming](/chat/streaming).

## 3. Attach context

1. Drop a file on the composer, or pick from [Library](/chat/library).
2. Chat attaches those Library items — never a URL you typed.
3. Images and files are accepted with type and size checks at upload.

## 4. Keep the thread in a project

Projects keep threads and Library files together.

1. Sign in if you have not already. Guests cannot create a project.
2. Open **Projects** in the Chat nav and create one.
3. Start the conversation inside that project. A later chat in the same project still sees that grouping.

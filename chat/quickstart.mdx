Get from open to a useful first conversation. Sign in if you want projects and tools; Chat also works as a guest.

## Open Chat

Launch [cortex.foundation](https://cortex.foundation) and select **Chat** from the product switcher.

<Frame>
```
Chat | Code | Bot
New chat · Attach · Tools
```
</Frame>

New chat starts a thread. It is an action, not a selected row in the sidebar.

## Start a project

Projects keep threads and Library files together. Create one from **Projects** in the Chat nav, then start the conversation inside it (`project_id` on the turn). A later chat in the same project still sees that grouping.

## Attach context

Drop a file on the composer or pick from Library. The turn sends `attachment_ids` — never a URL you typed. Images and files are accepted with type and size checks at upload.

Chat can keep short memories on your account. They follow you across threads. They are not a project, and they are not a Design canvas.

<Frame>
  <img src="/images/frames/chat-projects.svg" alt="Account-scoped memory sits outside any one Chat project" />
</Frame>

## What memory is

- User-scoped — not pinned to a project.
- Short — things Chat should remember next time, not a document store.
- Explicit to forget — deleting a memory is a delete, not a buried toggle.

## Review and forget

1. Open the product's memory list for your account.
2. Read what Chat stored.
3. Delete anything you do not want kept.

Forgetting is an explicit delete. See [Accounts](/getting-started/accounts) for export and account deletion.

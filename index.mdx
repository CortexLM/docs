<code>docs.cortex.foundation</code>

Cortex is one account across three products and a terminal client: **Chat** for conversation and research, **Code** for work inside a repository, **Bot** for tasks on a computer, and the **CLI** to drive Code from a shell. This site documents all four, plus the public API error reference.

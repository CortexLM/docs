# Product screenshot hooks

These four PNGs are **the** slots for real Cortex app screenshots from
staging. Overwrite the files in place. Do not add abstract product-window
SVGs. Do not invent extra mock plates.

Until the staging set lands, each file is a **marked placeholder** on the
real Cortex CLI forest wallpaper (cream card, ink type, `#1F4945` focus).
Alt text on every MDX use starts with `Placeholder — staging screenshot pending`.

| File | Surface | Used on |
| --- | --- | --- |
| `chat-home.png` | Chat home / projects / product switcher | Home, Get started (quickstart, what-is, accounts), Chat hub, projects, library, sharing, memory |
| `chat-session.png` | Chat thread | Chat overview, quickstart, how-it-works, streaming, voice, canvases, tools, Deep Research, images, origin check |
| `code-home.png` | Code home / desktop | Code hub and guides, Get started desktop |
| `bot-home.png` | Bot home / Computer rail | Every Bot guide |

Design canvas screenshots are not in this first set. Design guides use a
Note (no mock window). Design desktop uses the CLI wallpaper until a
real Design PNG arrives.

Cream `#FAF8F4` · ink `#211F1C` · green `#1F4945`. No violet.

A Design canvas is not a Chat project and not a Chat markdown sidecar. Frames, options, notes, and a Library drawer live on the board.

<Frame>
  <img src="/images/product/design-home.png" alt="Cortex Connectors under Customize — search, discover, and connect apps" />
</Frame>

The working UI is a separate desktop app. There is no `/design` tree in the web app and no Design segment on the Chat | Code | Bot switcher.

You must be signed in. Another account's canvases are not visible.

## Start from Chat or Code

1. Sign in.
2. Host a canvas from Chat or from Code. Chat and Code can write frames through their design tools. Bot does not receive those tools.
3. Open the board in the [Design desktop](/design/desktop) app.

See [Canvases](/design/canvases) and [Library](/design/library).

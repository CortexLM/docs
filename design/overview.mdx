<img src="/images/card-design.svg" alt="" />

A Design canvas is not a Chat project and not a Chat markdown sidecar. Frames,
options, notes, and a Library drawer live on the board.

The working UI is a separate desktop app. There is no `/design` tree in the
web app and no Design segment on the Chat | Code | Bot switcher.

You must be signed in. Another account's canvases are not visible.

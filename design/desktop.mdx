The Design working UI is a desktop app of its own. The web app creates and lists canvases when Chat or Code hosts one; editing frames, notes, options, and the Library drawer happens here.

## Install

<Steps>
  <Step title="Download">
    Desktop builds are published at [releases.cortex.foundation](https://releases.cortex.foundation). Pick the Design desktop app for your platform.
  </Step>
  <Step title="Sign in">
    Same account as the web app. Canvases are member objects.
  </Step>
  <Step title="Open a canvas">
    Your canvases follow your account. Boards hosted from Chat or Code are already listed.
  </Step>
</Steps>

## Work on a board

Edit frames and notes, lay out options side by side, and pull components, pages, and tokens from the Library drawer. Rename the board from **Untitled canvas** to something useful; the host binding to the originating Chat conversation or Code session stays.

## What the web app will not do

| | Web app | Design desktop |
| --- | --- | --- |
| Create a canvas from Chat or Code | Yes | — |
| List your canvases | Yes | Yes |
| Edit frames, notes, options | No | Yes |
| Library drawer | No | Yes |
| Design segment on the Chat · Code · Bot switcher | No | — |

## Three desktop apps

| App | Carries |
| --- | --- |
| [Cortex desktop](/getting-started/desktop) | Chat and Code, with This PC and SSH hosts |
| [Cortex Bot desktop](/bot/desktop) | Agents, routines, channels |
| **Cortex Design desktop** | Canvases and the Library drawer |

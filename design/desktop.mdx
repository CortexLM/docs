## 1. Install

Download Cortex from [releases.cortex.foundation](https://releases.cortex.foundation). Sign in from the app when it asks. See [Desktop app](/getting-started/desktop).

## 2. Open a canvas

Chat and Code can still write frames through their design tools. Bot does not receive those tools. Open the board on desktop to edit frames, notes, and the Library drawer.

## 3. What the web app will not do

No Design segment on the Chat | Code | Bot switcher. No working canvas in the browser. Hosting from Chat or Code still creates the object; the desktop app is where you work.

A Design canvas starts as **Untitled canvas**. You can host one from Chat or from Code. Deleting it hides it from the list.

<Frame>
  <img src="/images/frames/design-canvas.svg" alt="Untitled canvas with Frame 01 selected and a note" />
</Frame>

## What lives on the board

| On the canvas | Not this object |
| --- | --- |
| Frames | A Chat project |
| Notes | A Chat markdown sidecar |
| Host binding to Chat or Code | A Code workspace file |

## Create and open

1. Sign in. Another account's canvases are not visible.
2. Host a canvas from Chat or Code. The default title is Untitled canvas.
3. Open the working UI in the [Design desktop](/design/desktop) app.
4. Delete hides it from the list.

Chat canvases stay markdown sidecars. See [Chat canvases](/chat/canvases).
